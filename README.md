# Adi 3D Portfolio

A free, static portfolio website for 3D modeling and engineering design.

## Quick start

1. Open `index.html` in a browser to preview the site.
2. Replace the placeholder project sections with your own images and descriptions.
3. Put your project images inside the `images` folder.
4. Update the email and profile links in `index.html`.

## Publish free with GitHub Pages

1. Create a GitHub account.
2. Create a new public repository named `yourusername.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
4. In the repository, open Settings → Pages.
5. Select the main branch as the source and save.
6. Your website will be available at `https://yourusername.github.io`.

No paid hosting is required.
